# 三国群雄传平台司令台

本地网页管理平台 + **官方 PC 微信** 定时群播报。

## 方案说明

1. 登录本机 **官方微信电脑版**  
2. 打开司令台，点 **「进入司令台」**  
3. 到点后由程序操作本机 PC 微信发群（优先独立聊天窗标题匹配）

## 播报分类与时间轴

| 类型 | 功能（可扩展） | 时间轴规则 |
|---|---|---|
| **赛季类** | 抢台子、镇国台子、四方都城 | 必须落在赛季 `[starts_at, ends_at)` 内才播 |
| **活动类** | 群英会、王城争锋 | 固定活动起止期内按星期播；结束后**无下一轮**，靠新活动配置补充 |
| **普通类** | 天子战、坚守城池、流寇攻城、钓鱼 | 每周/每日固定循环，不依赖赛季/活动期 |

扩展：在 `backend/broadcast_kinds.py` 的 `FEATURE_KIND` 登记新功能名与类型即可。

## 功能要点

1. **抢台子**（赛季）：平日开始整点 / 周一独立开始整点；与镇国冲突只播镇国  
2. **镇国台子**（赛季）：星期 / 整点；周一可单独起始整点  
3. **四方都城**（赛季）：平日与周末分别配置进攻/防守与都城  
4. **群英会 / 王城争锋**（活动）：星期 + 时段 + **活动开始/结束**  
5. **天子战**（普通）：默认每周三、周日固定循环  
6. **坚守城池 / 流寇攻城**（普通）：每周固定时刻  
7. **钓鱼**（普通）：默认每日 **18:00**  
8. **忙时窗口**：默认 9–23，窗外不发  
9. **赛季进度条**：顶部展示 S2 阶段与剩余时间  
10. **试发**：只发测试群，不打目标群  

### 通用能力（全部播报）

| 能力 | 说明 |
|---|---|
| **提前 N 分钟** | 相对目标时刻提前播报（含坚守；`0` 表示准时） |
| **@所有人** | 可选开关，默认关闭；**优先于 @成员**（两者同时开只 @所有人） |
| **@部分成员** | 可选，昵称须与群内显示完全一致；合并消息里若已有 @所有人则隐藏成员 |

> **时间含义**：`开始整点=9` + `提前=5` 表示 **08:55** 提醒抢 09:00 的台。

## 装机清单（写死，换机必做）

| 项 | 要求 | 一键脚本是否覆盖 |
|---|---|---|
| 系统 | Windows 10/11 x64 | — |
| Python | **3.12**（推荐 3.12.10） | ✅ `install.bat`（winget） |
| 项目依赖 | `requirements.txt` → `.venv` | ✅ `install.bat` |
| 微信 | 官方 **PC 微信**已安装并登录 | ⚠ 仅检测，需人工安装/登录 |
| 微信窗口 | 建议目标群/测试群拉成**独立窗并置顶** | 人工 |
| 群名 | 与微信群显示名（窗标题）一致 | 人工（`config/settings.json`） |
| 首次验证 | 先开「演练模式」或「试发到测试群」 | 人工 |

## 换机一键部署

1. 复制整个项目目录到新电脑（可排除旧机器的 `.venv`）  
2. **双击 `install.bat`**  
3. 安装并登录官方 PC 微信，打开主窗口；建议把目标群/测试群拉成独立窗  
4. 双击 `start.bat`  
5. 浏览器打开 http://127.0.0.1:8765 →「进入司令台」  
6. 填群名与赛季/活动期 → **试发到测试群** → 再关演练正式播报  

可选 npm：

```bash
npm run install:app   # 等同 install.bat
npm start             # 等同 start.bat
```

## 日常使用

1. 保持 PC 微信已登录，目标/测试群独立窗可用  
2. 启动 `start.bat`  
3. 进入司令台配置（尤其是赛季起止、活动起止）并保存  
4. 试发/正式发送时建议先关掉浏览器开发者工具，避免抢焦点  

## 注意事项

- 群名、@ 成员昵称须与微信群内显示完全一致  
- `@所有人` 影响群体验，建议仅重要场次开启  
- 同一功能内 `@所有人` 与 `@成员` 同时开启时，只执行 `@所有人`  
- 合并播报中只要有一条开了 `@所有人`，整条消息只 @ 一次所有人，不再 @ 成员  
- 演练模式只写日志，不真实发消息  
- 活动类结束后不会自动开下一轮，需填写新的活动开始/结束时间  
- 赛季结束后赛季类自动停播；普通类仍按周循环
