# 三国群雄传平台司令台

本地网页管理平台 + **官方 PC 微信** 定时群播报。

## 方案说明

1. 登录本机 **官方微信电脑版**  
2. 打开司令台，点 **「进入司令台」**  
3. 到点后由程序操作本机 PC 微信发群  

## 功能

1. **抢台子**：周一至周日，9–24 点，整点提前 N 分钟；周日 24 点可跳过  
2. **坚守城池**：默认 12:00 / 12:30，城池复选  
3. **镇国台子**：星期 / 整点 / 提前分钟 / @ 成员可配  
4. **四方都城**：默认工作日 13:00，进攻/防守 + 都城复选  

配置保存后即时生效。

## 换机部署（放到另一台 Windows）

1. 安装 **Python 3.12**、官方 **微信电脑版**  
2. 复制整个项目目录到新电脑（可排除 `.venv`）  
3. 双击 `start.bat`（会自动建虚拟环境并装依赖）  
4. 登录官方 PC 微信  
5. 浏览器打开 http://127.0.0.1:8765 →「进入司令台」  
6. 填写群名 → 先开演练模式试发 → 再关演练正式播报  

配置在 `config/settings.json`，换机后按新环境重新填群名即可。

## 日常使用

1. 保持 PC 微信已登录  
2. 启动 `start.bat`  
3. 进入司令台配置并保存  
4. 发送时微信窗口可能被短暂置前，请勿最小化到托盘导致无法操作（视系统而定）  

## 注意事项

- 群名、@ 成员昵称须与微信群内显示完全一致  
- 演练模式只写日志，不真实发消息
