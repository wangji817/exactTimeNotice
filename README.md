# 三国群雄传平台司令台

本地网页管理平台 + **官方 PC 微信** 定时群播报。

## 方案说明

1. 登录本机 **官方微信电脑版**  
2. 打开司令台，点 **「进入司令台」**  
3. 到点后由程序操作本机 PC 微信发群  

## 功能

1. **抢台子**：周一至周日，9–24 点，整点提前 N 分钟；周日 24 点可跳过  
2. **坚守城池**：默认 12:00 / 12:30，城池复选  
3. **镇国台子**：星期 / 整点 / 提前分钟 / @ 成员可配  
4. **四方都城**：默认工作日 13:00，可提前 N 分钟，进攻/防守 + 都城复选  
5. **流寇攻城**：默认每日 10:00 / 15:00，可提前 N 分钟播报  

配置保存后即时生效。

> **时间含义**：`开始整点=9` + `提前=5` 表示 **08:55** 提醒抢 09:00 的台，不是 09:00 才播报。

## 装机清单（写死，换机必做）

| 项 | 要求 | 一键脚本是否覆盖 |
|---|---|---|
| 系统 | Windows 10/11 x64 | — |
| Python | **3.12**（推荐 3.12.10） | ✅ `install.bat`（winget） |
| 项目依赖 | `requirements.txt` → `.venv` | ✅ `install.bat` |
| 微信 | 官方 **PC 微信**已安装并登录 | ⚠ 仅检测，需人工安装/登录 |
| 微信窗口 | 主界面可打开（勿只留托盘） | 人工 |
| 群名 | 与微信群显示名完全一致 | 人工（`config/settings.json`） |
| 首次验证 | 先开「演练模式」试发 | 人工 |

## 换机一键部署

1. 复制整个项目目录到新电脑（可排除旧机器的 `.venv`）  
2. **双击 `install.bat`**（自动：装 Python 3.12 → 建 `.venv` → 装依赖 → 检测微信）  
3. 安装并登录官方 PC 微信，打开主窗口一次  
4. 双击 `start.bat`（若未装机过会自动再跑装机）  
5. 浏览器打开 http://127.0.0.1:8765 →「进入司令台」  
6. 填群名 → **先开演练模式试发** → 再关演练正式播报  

可选 npm：

```bash
npm run install:app   # 等同 install.bat
npm start             # 等同 start.bat
```

## 日常使用

1. 保持 PC 微信已登录，主窗口可被唤起  
2. 启动 `start.bat`  
3. 进入司令台配置并保存  
4. 试发/正式发送时建议先关掉浏览器开发者工具，避免抢焦点  

## 注意事项

- 群名、@ 成员昵称须与微信群内显示完全一致  
- 演练模式只写日志，不真实发消息  
- 发送超时或失败时，先确认微信主窗口可见、群名正确，再重试试发
